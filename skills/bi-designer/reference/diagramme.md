## 1. Palettes (from MARKE.md, chart order)
| Use | Order |
|---|---|
| Categories (bars, areas, pies) | `#08312A` Dark Green · `#00E47C` Accent Green · `#076D7E` Dark Blue · `#6AD2E2` Medium Blue · `#E18600` Dark Yellow · `#EE6541` Medium Red · `#5D4495` Dark Violet · `#928BDE` Medium Violet · `#86251B` Dark Red · `#FFD03D` Medium Yellow |
| Lines and small markers on white | `#08312A` · `#076D7E` · `#5D4495` · `#86251B` · `#EE6541` · `#E18600` (last two ≥ 2 px or with markers) – no Accent Green, no Medium Blue/Yellow as thin lines |
| Status | success `#00E47C` fill + `#08312A` text · info `#D2F2F7` + `#076D7E` · warning `#FFD03D` + `#08312A` · error `#F5CDB9` + `#86251B` · neutral `#E5E3DE` + `#08312A` |
| Sequential (one measure) | `#F6F5F3` → `#D2F2F7` → `#6AD2E2` → `#076D7E` → `#08312A` |
Axis, labels, titles Dark Green; grid and borders Warm Gray `#E5E3DE`; background White or Light Gray.
No 3D, no gradients, no shadows; legends only when more than one series.

## 2. matplotlib [D]
```python
import matplotlib as mpl
from cycler import cycler
CHART = ["#08312A", "#00E47C", "#076D7E", "#6AD2E2", "#E18600", "#EE6541", "#5D4495", "#928BDE", "#86251B", "#FFD03D"]
mpl.rcParams.update({
    "axes.prop_cycle": cycler(color=CHART), "font.family": ["Segoe UI", "DejaVu Sans"],
    "text.color": "#08312A", "axes.labelcolor": "#08312A", "xtick.color": "#08312A", "ytick.color": "#08312A",
    "axes.edgecolor": "#E5E3DE", "axes.grid": True, "grid.color": "#E5E3DE",
    "axes.spines.top": False, "axes.spines.right": False, "figure.facecolor": "#FFFFFF"})
```

## 3. Plotly [D]
```python
import plotly.graph_objects as go, plotly.io as pio
pio.templates["bi"] = go.layout.Template(layout=dict(
    colorway=CHART, font=dict(family="Segoe UI", color="#08312A"),
    paper_bgcolor="#FFFFFF", plot_bgcolor="#FFFFFF",
    xaxis=dict(gridcolor="#E5E3DE", linecolor="#E5E3DE"), yaxis=dict(gridcolor="#E5E3DE", linecolor="#E5E3DE")))
pio.templates.default = "bi"
```

## 6. draw.io / SVG / own icons
- draw.io style: `fillColor=#F6F5F3;strokeColor=#08312A;fontColor=#08312A;fontFamily=Segoe UI;rounded=0;`;
  emphasis `fillColor=#08312A;fontColor=#FFFFFF`.
- SVG: colors only as tokens (CSS variables or constants), square corners, stroke Dark Green.
- Domain icons missing in the brand set (e.g. process equipment) may be drawn in the brand line style:
  same stroke weight as the set at 512 px, transparent background, delivered in the four variants
  darkgreen/accentgreen/black/white, generated by a script in the project, listed in DESIGN.md as „eigene
  Icons“ [B – ReiRue R&I icons].
